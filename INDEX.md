# Smartcat design system — index

The manifest the `smartcat-design-system` loader skill reads **first**, so it can open only the few files a task actually needs.

> Generated by `skills/smartcat-design-system/scripts/build-index.py`. Do not edit by hand — re-run the script after adding or changing a component.

Full corpus ≈ 116,059 tokens — **never read it all.** `sync.sh` reports the commit you are actually on.

## Reading order

1. This file.
2. The rules for the ONE output format in play (see the table below) — not all five.
3. `tokens/` only when you need a specific token value; the format rules name the ones that matter.
4. The 3–5 component files the task actually calls for.
