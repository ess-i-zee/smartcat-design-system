This article provides an end-to-end workflow for using Smartcat to translate from Adobe Experience Manager (AEM). It walks through step-by-step instructions for Smartcat users translating and reviewing content from AEM.

Accessing the file

1

Receive an email from your Workspace Admin that invites you to review a project in that workspace. The email is from Smartcat.

2

Open the email to review the details of the task, including the administrator who invited you and the task to which you've been assigned.

3

Click Go to Task to open the task in Smartcat.

4

Sign in to Smartcat.

5

Smartcat opens to the accepted project on your Personal Tasks page. From the project preview, click the tabs at the top of the pop-up to review the Files in the project, an Overview of the project — including the number of words and the source and target languages — and Smartcat's linguistic-asset Statistics for the project.

Reviewing and editing the file

1

Smartcat displays a live preview of the AEM page in the target language. The live preview lets you view the translation in the context of the original page.

2

Review the page translation and confirm segments. Hover over a section of text and click the Edit (pencil) icon to view the source and target translation.

Hover over the AI box on the right side of the panel to view the translation source and any AI insights. Make changes by clicking into the right-hand box and entering them, then confirm the segment.

3

Click outside the pop-up to close it, then navigate to other segments in the live preview, or use the arrows at the bottom of the pop-up.

Track the number of confirmed words in the progress bar at the top of the screen, and continue until Translation review reaches 100%.

Navigating to other files in the project

1

When you've finished reviewing a translation, select another file in the project from the file dropdown, then click its name to open it. Repeat the review and confirmation for every file in the project.

The .json files in a project don't show their file extension in the dropdown.

Tips and keyboard shortcuts

Tips for using the editor

  • View the translation source — see whether a segment was translated by AI or pulled from translation memory.
  • See notifications for spelling or grammar errors, and read comments left by a colleague or an external linguist.
  • See the in-context preview of the target text, when the format supports it, and search the source or target text for specific entries.

Keyboard shortcuts

  • Confirm a segmentCtrl+Enter
  • Go to next unconfirmedF9
  • Jump to a segmentCtrl+G
  • UndoCtrl+ZRedoCtrl+Y
  • Copy source to targetCtrl+Insert
  • Find and replaceCtrl+H
  • Change caseShift+F3
